# MODULE — application

> Паспорт модуля. 30–50 строк. Единственное, что другие агенты знают о модуле,
> не читая код. Обновляется в сессии, где менялся интерфейс/зависимости/инварианты.

## Назначение

Прикладной слой между ядром и UI. Сейчас — персист прогресса (`ProgressService`).
Слой тонкий: игрового цикла нет — в `presentation/screens/game_screen` есть только
пульс-`AnimationController` (анимация `doneGlow`).

## Публичный интерфейс

- `ProgressService` (персист хранит **число собранных деталей** 0..N, N =
  `RoninParts.parts.length`; Ронин-1/05 T1 — было «индекс уровня» 0..N−1, смысл тот же:
  уровень i ⇔ собрано i, но выражается «собраны все N» — финал):
  - `getCollectedCount() → Future<int>` — собрано 0..N (по умолчанию 0).
  - `getCurrentLevel() → Future<int>` — `min(собрано, N − 1)` (контракт прежний: валидный
    индекс уровня 0.._max).
  - `completeLevel(int levelIndex) → Future<int>` — засчитать деталь: собрано =
    `max(собрано, levelIndex + 1)`, кламп 0..N; идемпотентно, не уменьшает. Зовёт
    `GameScreen` в момент сборки (до выбора маршрута на паузе).
  - `setCollectedCount(int)` — собрано n, кламп 0..N (чит «Состояние корабля»).
  - `setCurrentLevel(int)` — сохранить (значение clamp-ится в 0.._max).
  - `reset()` — сброс прогресса (только отладка/тесты и дев-кнопка финала).
  - Прежний «следующий уровень после победы» удалён (Ронин-1/05 T1) → `completeLevel`.
  - `_max` — **не хардкод**: `RoninParts.parts.length - 1` (Ронин-1/01 T3; эпик
    «Контент» — единый источник истины числа уровней; см.
    hotfix 2026-07-11 — было захардкожено `15` из «Мета-каркаса», разошлось с `LevelMap`
    (7 уровней) и роняло приложение на холодном старте с устаревшим persist-значением).

## Зависит от

- `game_engine/data` — `RoninParts.parts.length` (единый источник истины `_max`). Внешнее:
  `shared_preferences` (persist).

## От него зависят

- `presentation` — `main.dart`, `game_screen`, `ship_screen` используют `ProgressService`.

## Инварианты

- Персист только через `shared_preferences`, ключ `current_level`, значение — собрано 0..N.
- Прогресс засчитывается один раз на деталь (`completeLevel` идемпотентен по уровню) и
  никогда не уменьшается, кроме `reset()`; финал (собрано N) прогресс не сбрасывает.
- `getCollectedCount()`/`getCurrentLevel()` клампят НА ЧТЕНИИ — устаревший/повреждённый
  persist (значение из старой сборки с другим числом уровней) самовосстанавливается до
  валидного, а не крашит `LevelMap`; `getCurrentLevel()` всегда ≤ N − 1.
- Слой не импортирует `presentation` (импорты только вниз); импортирует `game_engine/data`
  (разрешено — импорт строго вниз по слоям, см. ARCHITECTURE).
