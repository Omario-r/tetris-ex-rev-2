# MODULE — game_engine/packing

> Паспорт модуля. 30–50 строк. Единственное, что другие агенты знают о модуле,
> не читая код. Обновляется в сессии, где менялся интерфейс/зависимости/инварианты.

## Назначение

Новое ядро укладки полиомино-кусочков в силуэт (эпик «Укладка», Стори 01):
модель кусочка, иммутабельное состояние укладки и контроллер команд
размещения/перекладки/снятия с валидацией, плюс детерминированный генератор
нарезки силуэта на кусочки. Чистый Dart, без Flutter.
Основной движок игры (эпик «Укладка», Стори 02: `GameScreen` пересажен на него,
старое тетрис-ядро удалено).

## Публичный интерфейс

- `PackPiece(id, cells)` — кусочек-полиомино; `cells` — нормализованные
  локальные клетки (`min x == 0`, `min y == 0`), 3..5 штук; `size`.
- `PackState(silhouette, placements, pieces, trayOrder)` — иммутабельный
  снапшот: `occupiedCells` (клетки уложенных кусочков в координатах силуэта),
  `isComplete` (силуэт покрыт полностью, без дыр и пересечений), `copyWith`.
- `PackController(initial)` — `state`; `place(pieceId, atX, atY)`,
  `move(pieceId, atX, atY)`, `remove(pieceId)`, `clear()` (все уложенные — в лоток в исходном порядке; no-op на
  пустом поле) — все no-op при невалидной
  команде; статик `PackController.canPlace(state, pieceId, atX, atY, {ignoreId})`
  — чистая функция валидации (внутри силуэта + без пересечений).
- `slicePolyomino(silhouette, {seed})` → `PackSlice` — детерминированный
  генератор нарезки: режет `TargetMask` на связные полиомино-кусочки по 3..5
  клеток (полный бэктрекинг-DFS с отсечением тупиковых веток, порядок размеров
  [4,5,3]). `PackSlice` =
  `pieces` (id 0..N-1, cells нормализованы) + `solution` (`pieceId → origin` в
  силуэте; эталонная раскладка, доказывающая существование решения).
- `slice_config.dart` — построение уровня из маски детали (Ронин-1/07, 08):
  `enum SliceConfig { bigPieces }` (dev-переключатель вариантов слияния, порядок =
  порядок кнопок чит-меню; стори 04 добавит второе значение);
  `prepareLevel(partMask, config, {seed})` → `PreparedLevel` (`fieldWidth/
  fieldHeight` = 10×14, `silhouette` размера поля, `targetX/targetY`, `slice`,
  `trayOrder`). `bigPieces` — нарезка 3..5 + слияние соседних (5..12 клеток,
  7–10 кусков). `trayOrder` (D-007) — перестановка id кусков от seed
  (`shuffle(Random(seed*7919+17))`), никогда не равна порядку по возрастанию id
  (порядок id = порядок решения; при `N >= 2` совпадение лечится сдвигом на 1).
  `mergeAdjacentPieces(silhouette, base)` — публичное детерминированное слияние
  (два прохода: пары нетронутых ≤ 10, затем остатки в любого соседа ≤ 12).

- `startMetric(silhouette, slice)` → `StartMetric(placesPerPiece, minPlaces)`
  (`start_metric.dart`) — метрика старта (DESIGN.md § «Сложность старта»): на
  пустом поле для каждого куска число сдвигов (без поворотов), при которых все
  его клетки внутри силуэта; среднее по кускам и минимум. Рамп сложности
  («вводная» нос/мостик ≤ 15 / ≤ 8, предметы ≤ 15, пояс 22–40) держит
  `test/game_engine/packing/start_metric_test.dart` на канонных seed деталей.

## Инварианты

- Чистый Dart: `import 'package:flutter/...'` запрещён.
- Команды контроллера — **no-op** вместо исключений (соглашение API движка,
  ARCHITECTURE «Сквозные соглашения»).
- Координаты: `(0,0)` слева сверху, `y` вниз; те же, что у `models`/`rules`.
- Размер кусочка — 3..5 клеток (инвариант держит потребитель — генератор
  нарезки/тестовые фикстуры; `PackPiece` сам это не проверяет).
- `slicePolyomino`: покрытие силуэта полное, без дыр и пересечений; куски 3..5,
  связны, нормализованы; детерминизм по seed (один `math.Random(seed)`); порядок
  размеров [4,5,3] (антивырождение). Отсечение (Ронин-1/04 T2): после выбора
  кандидата, до рекурсии, остаток с компонентой < 3 клеток не раскрывается
  (откат кандидата). Отсекает только безнадёжные ветки (остаток с островком
  < 3 клеток), разрезаемость сохраняется; нарезка при данном seed может
  отличаться от версии без отсечения, потому что общий `Random(seed)` больше не
  тратится в тупиках; канонные нарезки 15 деталей зафиксированы эталоном
  `_referenceSlices` в `pack_slicer_test`. Нарезка любой детали «Ронина» на
  seed 0..15 — единицы мс (бюджет 500 мс держит `slice_config_test.dart`). Валидный силуэт всегда режется; неразрезаемый
  → `StateError` (НЕ штатный no-op — генератор обязан резать валидный контент).
- `placements` содержит только уложенные кусочки; `trayOrder` — только
  неуложенные; каждый `pieceId` — в ровно одном из двух мест или ни в одном
  (до первой укладки он в `trayOrder`).
