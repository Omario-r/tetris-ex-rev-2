# MODULE — game_engine/packing

> Паспорт модуля. 30–50 строк. Единственное, что другие агенты знают о модуле,
> не читая код. Обновляется в сессии, где менялся интерфейс/зависимости/инварианты.

## Назначение

Новое ядро укладки полиомино-кусочков в силуэт (эпик «Укладка», Стори 01):
модель кусочка, иммутабельное состояние укладки и контроллер команд
размещения/перекладки/снятия с валидацией. Чистый Dart, без Flutter.
Параллельно старому тетрис-ядру (`game`/`rules`) — то не трогает.

## Публичный интерфейс

- `PackPiece(id, cells)` — кусочек-полиомино; `cells` — нормализованные
  локальные клетки (`min x == 0`, `min y == 0`), 3..5 штук; `size`.
- `PackState(silhouette, placements, pieces, trayOrder)` — иммутабельный
  снапшот: `occupiedCells` (клетки уложенных кусочков в координатах силуэта),
  `isComplete` (силуэт покрыт полностью, без дыр и пересечений), `copyWith`.
- `PackController(initial)` — `state`; `place(pieceId, atX, atY)`,
  `move(pieceId, atX, atY)`, `remove(pieceId)` — все no-op при невалидной
  команде; статик `PackController.canPlace(state, pieceId, atX, atY, {ignoreId})`
  — чистая функция валидации (внутри силуэта + без пересечений).

## Инварианты

- Чистый Dart: `import 'package:flutter/...'` запрещён.
- Команды контроллера — **no-op** вместо исключений (как `GameController`).
- Координаты: `(0,0)` слева сверху, `y` вниз; те же, что у `models`/`rules`.
- Размер кусочка — 3..5 клеток (инвариант держит потребитель — генератор
  нарезки T2/тестовые фикстуры; `PackPiece` сам это не проверяет).
- `placements` содержит только уложенные кусочки; `trayOrder` — только
  неуложенные; каждый `pieceId` — в ровно одном из двух мест или ни в одном
  (до первой укладки он в `trayOrder`).
