# Voxel Voyager

Мобильный пазл-сборка на Flutter. Уровень — силуэт детали космического корабля
и лоток кусочков-полиомино, нарезанных из этого же силуэта. Игрок перетаскивает
кусочки в силуэт, пока не заполнит его без дыр. Собранные детали складываются
в один большой воксельный корабль «Ронин», который растёт по частям.

Без таймера, гравитации и проигрыша; уложенный кусок всегда можно переложить.

Проект ведут ИИ-агенты по ролевой методике (см. «Как устроена работа»), цель —
довести игру до публикации в сторе. Сейчас режим — прототип, идут плейтесты.

> Имя пакета `explosive_tetris` и название репозитория остались от первой
> версии ядра (тетрис со взрывом), которую заменила точная укладка.

## Запуск

Нужны Flutter SDK, для iOS — Xcode.

```bash
flutter pub get
```

```bash
flutter run
```

Установка на свои iPhone/Android free-signing'ом, список устройств — в
[docs/RUNBOOK-devices.md](docs/RUNBOOK-devices.md).

Чит-меню (выбор уровня, мгновенное завершение, состояние корабля) включено в
любой сборке флагом `DEV_TOOLS` (D-018). Выключить:

```bash
flutter run --dart-define=DEV_TOOLS=false
```

Веб-таргет (`web/`) служебный — только для проверки агентом в браузере, не
платформа публикации.

## Проверки

```bash
flutter analyze
```


## Структура

| Путь | Что там |
|------|---------|
| `lib/game_engine/` | Ядро: модели, укладка и нарезка силуэта, разметка деталей «Ронина» |
| `lib/application/` | Прогресс, флаги сборки |
| `lib/presentation/` | Экраны, пейнтеры, рисунок корабля, скины |
| `test/` | Автотесты по тем же слоям |
| `docs/` | Продуктовые документы, эпики, дизайн |
| `system/` | Правила ролей агентов (генерик, синхронизируется с шаблоном) |
| `tool/` | Генератор иконки приложения |

Карта модулей и связей — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md); у
каждого модуля в `lib/` свой `README.md`-паспорт.

## Как устроена работа

Решения принимает PO (владелец продукта), код и документы пишут агенты Claude
Code в ролях: Советник, Дизайнер, Постановщик, Исполнитель, Критик, Методолог.
Роль выбирается командой PO — маршрут в [CLAUDE.md](CLAUDE.md), правила ролей
в `system/`, адаптации этого проекта (стек, гейт качества, ростер) — в
[PROJECT.md](PROJECT.md). Эксперимент автономного ведения продукта —
[docs/producer/PRODUCER.md](docs/producer/PRODUCER.md).
