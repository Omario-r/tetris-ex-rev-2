КНОПКА ВЗРЫВА — СОСТОЯНИЯ

×3

Готов — есть заряды. Тап — взвести. Канистра спокойная, hazard-полоса горит оранжевым.

×3

Взведён — жми — рванёт. Кнопка горит: ядро, кольца, искры, свечение/пульс. Тап — детонация.

×0

Пусто — 0 зарядов, неактивна. Полосы гаснут в серый, счётчик серый, кнопка задимлена.

Системная зона (конвенции игры на мобилке): верхний/нижний safe-area соблюдены (пунктир на рамке); все контролы ≥ 56 px; портрет; back-жест Android = пауза, не выход. Механика взрыва (#3) не меняется — только UI-триггер.

КАТАЛОГ ЭЛЕМЕНТОВ ПОЛЯ — КАНОН, ЯКОРЯ ДЛЯ ТЗ

Каждый элемент — отдельная спека: ТЗ ссылается на имя (el-…), а не на «как в мокапе». Показ ×2 (клетка 68 px); размеры в аннотациях — при базовой клетке 34 px. Общий кадр слева — только композиция.

el-empty — пустая клетка
фон boardBg; линии сетки gridLine по правой и нижней границе клетки, 1 px.
el-target — клетка мишени
пунктир ghostTarget 1.5 px, инсет 3 px, скругление 3 px; заливка hazardOrange 5%.
el-block — блок в мишени
заливка = материал детали (карта ShipMaterials); фаска: свет сверху 9% бел. 3 px, тень снизу 35% чёрн. 3 px, свет слева 4% / тень справа 18%; 4 ривета по углам (точка Ø 3 px, 45% чёрн., отступ 4 px); скругление 3 px, зазор 1 px от клетки.
el-scrap — блок вне мишени
заливка graphiteDark; фаска слабее (5% / 30%); БЕЗ риветов; питтинг: 2–3 пятна rust-тонов Ø 2 px + тёмная точка, позиции псевдослучайны от координат клетки (стабильны между кадрами).
el-piece — падающая фигура
нейтральный graphite (материалом красится ТОЛЬКО при локе в мишени); фаска ярче (свет 12%); лёгкое внешнее свечение бел. 6%; риветы как у el-block.
та же фигура группой (тетромино) —
хэтч и свечение тайлятся по клеткам
el-piece-armed — взведённая фигура (утв. PO 2026-07-19)
падающая фигура в режиме armed (взрыв взведён, детонирует при локе) — красится ВСЯ фигура, поклеточно.
База — el-piece (графит, фаска ярче 12%, риветы по углам) — фигура остаётся узнаваемой.
+ диагональный hazard-хэтч (45°, полоса 6 px / зазор 8 px, armedHatch = hazardOrange 55%) — ДНК канистры-заряда.
+ горячее внешнее свечение armedGlow (hazardOrange 55%, 20 px) + hazard-подкрас верхней фаски (hsla 23,62%,70%, 20%).
+ ембер-ядро в центре клетки (13 px, armedEmber заливка, свечение armedEmberGlow) — те же значения, что ядро взведённой кнопки.
Пульс альфы свечения — как у el-halo / взведённой кнопки (период не меняем).
el-drop — drop-ghost
контур 1 px бел. 16%, инсет 2 px, скругление 3 px; без заливки.
el-drop-armed — drop-ghost взведённой (утв. PO 2026-07-19)
точка падения, пока фигура взведена. Тот же контур, что el-drop, но в цвете ембер-ядра (это взрыв): сплошной контур armedEmberGlow (1 px, инсет 2 px) — сплошной, а не пунктир, чтобы не путать с мишенью (el-target). + слабая тёплая заливка (armedEmberGlow 10%) + мягкое свечение ембера внутри и снаружи. Показывает, куда рухнет бомба.
el-halo — пульс-подсветка
рамка hazardOrange 55% → пульс альфы (существующее поведение HaloHighlightOverlay, период не меняем); лёгкое свечение. ПРЕДЛОЖЕНИЕ — утвердить отдельно: в старом виде цвет был иным.
