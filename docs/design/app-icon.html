Иконка приложения — «Заряд» (утверждена PO 2026-07-18)

Канистра-заряд с кнопки взрыва — единый объект визуального языка игры, читается на всех размерах. Фон — матовый чёрный, палитра — токены «Ронина».

180 px — стор/маркетинг
104 px — домашний экран
56 px — настройки/поиск
VOXEL VOYAGER
имя приложения: «Voxel Voyager» (из VISION; влезает ли под иконкой на обеих ОС — проверить на устройстве в стори 03)
Конвенция-чек: обе ОС маскируют иконку сами (iOS — суперэллипс, Android — adaptive icon: круг/скруглённый квадрат), поэтому исходник — квадрат с центрированной канистрой и полем-отступом, без «запечённых» углов; для Android отдать foreground (канистра) + background (матовый чёрный) слоями.
