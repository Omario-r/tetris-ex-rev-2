# ROADMAP — очередь эпиков

> Порядок = приоритет. Наполняется на сессиях советника, статусы обновляет
> исполнитель на гейтах. VISION отвечает «куда идём», ROADMAP — «что делаем по пути».

| # | Эпик | Статус |
|---|------|--------|
| 1 | Мета-каркас корабля (`docs/epics/meta-karkas/`) | в работе |
| 2 | Контент: корабль из 10–12 деталей, кройка мишеней | в очереди (EPIC.md — на отдельной сессии) |
| 3 | Взрыв с лимитом зарядов | в очереди (EPIC.md — на отдельной сессии) |
| 4 | Плейтест-сборка: стиль, устройства, плейтест | в очереди (EPIC.md — на отдельной сессии) |

## Уроки закрытых эпиков

> 1–2 строки на эпик после Гейта 3: что учесть в следующих. Советник читает
> перед каждой сессией. Полное ревью — в EPIC.md соответствующего эпика.

- <эпик>: <урок>
