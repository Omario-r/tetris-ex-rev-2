## Ценность

Игрок может **увидеть собранную деталь целиком, без сетки, а на экране корабля —
успеть заметить, куда она встаёт**, чтобы **связка «собрал → прирос» считывалась
сильнее (успех #2 VISION)**; лишняя подпись и режим лотка, которым никто не
пользуется, уходят.

## Критерии приёмки

- [x] **Пауза перед въездом детали** на экране корабля после сборки
      (`ShipScreen.afterWin` и финал с `animateLast`): сначала корабль без новой
      детали, затем деталь въезжает. Длительность паузы — одна именованная
      константа (стартовое значение — при нарезке; PO щупает на устройстве).
      _Доказательство: `ShipScreen.kRevealDelay` = 600 мс; `ship_screen_test` —
      `revealProgress == 0` на `kRevealDelay − 50 мс`, `== 1` после паузы + въезда._
- [x] **Собранная деталь на поле — целиком, без сетки:** на паузе «ДЕТАЛЬ
      СОБРАНА» швы `seam` между клетками не рисуются — деталь видна сплошным
      куском рисунка. Во время укладки швы как сейчас.
      _Доказательство: `packing_painter_test` (seamless: граница = эталон
      `paintPartCell`, со швом темнее), `game_screen_test` (на паузе
      `seamless == true`, на укладке `false`)._
- [x] **Подписи лотка нет** («ЛОТОК · ПОЛНЫЙ НАБОР» / «ПОРЦИЯ-3»), высота зоны
      лотка не меняется (поле не прыгает).
      _Доказательство: `game_screen_test` — текста `ЛОТОК` нет, высота
      `packing_tray` = 206 и равна `done_buttons`._
- [x] **Режима «Лоток-3» нет** (D-015): `FeedMode`, ветка `tray3`, секция
      «Подача» чит-меню и их тесты сняты; лоток всегда показывает полный набор.
      _Доказательство: `grep -rn "FeedMode\|tray3\|feed_full\|ЛОТОК ·" lib test` — пусто._
- [x] `flutter analyze` — 0; `flutter test` — зелёный.
      _Доказательство: «No issues found!»; «+475: All tests passed!»._
