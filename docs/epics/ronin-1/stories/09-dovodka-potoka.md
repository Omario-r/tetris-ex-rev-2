# STORY 09 — Доводка потока и лотка (замечания PO на КТ-2)

**Эпик:** Ронин-1 — первые модули корабля
**Статус:** не начата (заведена 2026-10-09 по замечаниям PO на КТ-2, INBOX)

## Ценность

Игрок может **увидеть собранную деталь целиком, без сетки, а на экране корабля —
успеть заметить, куда она встаёт**, чтобы **связка «собрал → прирос» считывалась
сильнее (успех #2 VISION)**; лишняя подпись и режим лотка, которым никто не
пользуется, уходят.

## Критерии приёмки

- [ ] **Пауза перед въездом детали** на экране корабля после сборки
      (`ShipScreen.afterWin` и финал с `animateLast`): сначала корабль без новой
      детали, затем деталь въезжает. Длительность паузы — одна именованная
      константа (стартовое значение — при нарезке; PO щупает на устройстве).
- [ ] **Собранная деталь на поле — целиком, без сетки:** на паузе «ДЕТАЛЬ
      СОБРАНА» швы `seam` между клетками не рисуются — деталь видна сплошным
      куском рисунка. Во время укладки швы как сейчас.
- [ ] **Подписи лотка нет** («ЛОТОК · ПОЛНЫЙ НАБОР» / «ПОРЦИЯ-3»), высота зоны
      лотка не меняется (поле не прыгает).
- [ ] **Режима «Лоток-3» нет** (D-015): `FeedMode`, ветка `tray3`, секция
      «Подача» чит-меню и их тесты сняты; лоток всегда показывает полный набор.
- [ ] `flutter analyze` — 0; `flutter test` — зелёный.
- [ ] **Гейт 2, визуально:** пауза перед въездом читается; собранная деталь без
      сетки; лоток без подписи; чит-меню без «Подачи».
