# STORY 10 — Разметка v3: швы по деталям, предметы отдельно, клетки-плитки

**Эпик:** Ронин-1 — первые модули корабля
**Статус:** в работе — модель принята PO 2026-10-09 (D-016), задачи нарезаны

## Ценность

Игрок может **собирать деталь из ровных рельефных плиток с покраской корабля, а
собранная деталь проявляется целиком и встаёт на корабль своим швом**, чтобы **не
было диссонанса «рельефный кусок в лотке — пёстрый плоский рисунок на поле», а
корабль читался как собранный из тех самых деталей** (замечание PO на КТ-2, п. 2а).

## Критерии приёмки

- [ ] Канон v3: `ronin-parts.js` (12 плит без язычка носа и одинарных шипов, уступы
      на нижних плитах; 7 предметов; 19 деталей), `ronin-objects.js` (визор
      половинами, люки), `ship-render.js` (плиты по деталям, мягкие швы, без сетки,
      визор выше), DESIGN.md — по мокапу `docs/design/ronin-seams.html`.
- [ ] В игре 19 деталей v3 в порядке мокапа; seed каждой — по метрике старта, рамп
      держится тестом; маски ≤ 10×14, ≤ 80 клеток, без одинарных шипов (тест).
- [ ] Экран корабля — плиты по деталям, предметы слоем 1 (визор, люки, датчик, RCS).
- [ ] Клетка поля во время сборки: рельеф Б; плита — рисунок без края детали и
      щелей-огней; предмет — преобладающий цвет клетки; заклёпки — чёрные 45 % /
      85 % на тёмной клетке.
- [ ] Собранная деталь: настоящий рисунок без рельефа и сетки, чёткая кромка.
- [ ] Лоток и кусок в руке — графит без изменений.
- [ ] `flutter analyze` — 0; `flutter test` — зелёный.
- [ ] **Гейт 2, визуально:** поле в сборке и собранное, экран корабля — против
      `ronin-seams.html`.
