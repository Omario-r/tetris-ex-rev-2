# STORY 02 — Иконка взрыва и объединённая кнопка

> Заполняет Постановщик при декомпозиции. PO утверждает на Гейте 1 и принимает
> на Гейте 2.

**Эпик:** Готовность к плейтесту
**Статус:** не начата

## Ценность

Контрол взрыва — **одна понятная кнопка в своём стиле** (воксельный заряд без TNT),
чтобы взрыв читался как своя механика, а не отсылка к Minecraft, и управление было
проще (одна кнопка вместо двух).

## Критерии приёмки

- [ ] Иконка заряда — воксельная (графит + оранжевый hazard), без TNT/Minecraft-отсылок.
- [ ] Активация и детонация — **одна кнопка** со сменой иконки по состоянию:
  Готов / Взведён / Пусто.
- [ ] На кнопке — счётчик оставшихся зарядов `×N`.
- [ ] Это UI-триггер **двух существующих** команд (активация + детонация из #3);
  механика, бюджет и правила детонации не тронуты — тесты движка/взрыва зелёные.
- [ ] `flutter analyze` — 0; вид кнопки/индикатора подтверждён скриншотом через Preview.

## Не входит

- Механика / бюджет / зона взрыва (#3, заморожено).
- Общий стиль поля и корабля — **Стори 01**.
- Иконка/имя приложения — **Стори 03**.

## Контекст для нарезки

- Команды активации и детонации уже существуют (`GameController`, эпик #3).
- HUD-кнопки arm/detonate — в `widgets` (`GameHud`); скин заряда (`TntSkin`) — в `theme`.
- Задача: заменить иконку на воксельный заряд; объединить две кнопки в одну со
  state-машиной (Готов/Взведён/Пусто) + счётчик `×N`; стилизовать индикатор зарядов.
- Ядро и бюджет зарядов не трогаем — только UI-слой (`theme` + `widgets`).

## Затронутые модули

- `lib/presentation/theme/` — иконка/скин заряда (замена `TntSkin`).
- `lib/presentation/widgets/` — `GameHud`: объединённая кнопка + индикатор зарядов.
- `test/` — обновление hud-тестов.
