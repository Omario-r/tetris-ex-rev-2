# STORY 01 — Свой воксельный стиль вместо Minecraft-визуала

**Эпик:** Готовность к плейтесту
**Статус:** не начата

## Ценность

Игрок видит **собственный узнаваемый воксельный космический стиль** поля, блоков, оверлеев и
корабля вместо текущего Minecraft-подобного визуала, чтобы сборка **не нарушала условие
публикации VISION** («свой блочный стиль; IP Minecraft не используем») и читалась как
намеренный арт-выбор, а не заглушка.

## Критерии приёмки

- [ ] Ни один материал/скин/оверлей/название в `presentation/theme` не отсылает к Minecraft:
  `grass/cobble/dirt`-подобные материалы, `TntSkin`, `CreeperFacePainter` — переименованы и
  визуально переработаны под собственный космический воксельный стиль (не просто
  переименование при старом виде — см. следующий пункт).
- [ ] HUD-подписи/иконки, ссылавшиеся на «крипер»/TNT (кнопки arm/detonate), заменены на
  нейтральные обозначения (заряд/взрыв), без чужого IP.
- [ ] Итоговый вид (поле, HUD, корабль) **читается как цельный намеренный воксельный
  космический стиль**, не заглушка — подтверждено скриншотом(-ами) через Preview-инструменты
  (`flutter run -d web-server`).
- [ ] Судьба `theme/image_block_skin.dart` (`ImageBlockSkin`, сейчас не подключён) решена
  явно: либо подключён как часть нового стиля, либо удалён как мёртвый код — не оставлен
  «как есть» без решения.
- [ ] `flutter analyze` — 0; все существующие тесты (`theme/block_theme`, `theme/level_skin`,
  `hud`, `board_painter`, `ship_screen`) зелёные после переименований.

## Не входит

- Ядро/правила/контент/мишени/halo — не трогаем (VISION-заморозка, EPIC.md «Не входит»).
- Частицы, звук/музыка, анимации-джус, финал-фанфары — production-полиш вне эпика.
- Иконка приложения и имя пакета/сборки — **Стори 02**.
- Взрыв/заряды и их HUD-индикатор как функциональность — эпик «Взрыв» (#3); здесь только
  стиль поверх уже готового индикатора (эпик «Взрыв» должен быть закрыт до этой стори — см.
  порядок в ROADMAP/STATUS).

## Затронутые модули

- `lib/presentation/theme/` — `BlockMaterial`, скины (`ProceduralBlockSkin`, `TntSkin` и
  наследники), оверлеи (`GhostTargetOverlay`, `HaloHighlightOverlay`, `CreeperFacePainter`),
  `LevelSkin` — маппинг уровень→материал под новый набор.
- `lib/presentation/widgets/` — `GameHud` — подписи/иконки кнопок, если ссылаются на текущие
  Minecraft-термины.
- `test/` — обновление тестов под переименования (theme, hud, board_painter).
