# STORY 01 — Экран корабля

> Заполняет агент при декомпозиции эпика. PO утверждает на Гейте 1 и принимает
> на Гейте 2. Работа по стори НЕ начинается, пока секция «Открытые вопросы к PO»
> не пуста.

**Эпик:** Мета-каркас корабля
**Статус:** не начата

## Ценность

Игрок может **открыть экран корабля из игры и увидеть, из каких деталей уже собран
его корабль**, чтобы **видеть свой прогресс сборки и то, что он строит что-то большое**.

## Критерии приёмки

- [ ] На игровом экране есть кнопка/иконка «Корабль»; тап открывает экран корабля,
  кнопка «Назад» возвращает в игру.
- [ ] Экран корабля показывает ЕДИНЫЙ корабль из 2–3 деталей-заглушек: собранные детали
  видны установленными, ещё не собранные — контуром/пусто.
- [ ] Число собранных деталей = числу пройденных уровней (пройден уровень N → деталь N на месте);
  проверяется чит-меню недоступно на этой стори — проверять прохождением или ручной установкой прогресса.
- [ ] Сохранение сборки: закрыть и снова открыть приложение → экран корабля показывает то же
  число собранных деталей (через существующий `ProgressService`, ключ `current_level`).
- [ ] `flutter analyze` — ноль; существующие тесты зелёные.

## Не входит

- Авто-показ корабля после победы — Стори 03.
- Реальные 10–12 деталей и их дизайн — эпик «Контент»; здесь только 2–3 заглушки.
- Анимации/частицы/звук; полноценное главное меню приложения.
- Финал «корабль собран полностью».

## Затронутые модули

> По карте из ARCHITECTURE.md. Если модуля ещё нет — пометить «(новый)».

- `lib/presentation/screens/` — новый экран корабля (ShipScreen) + вход из игрового экрана.
- `lib/presentation/widgets/` — отрисовка корабля из деталей (адаптировать `ObjectFullPainter`).
- `lib/application/` — чтение сохранённого прогресса (`ProgressService`, уже есть).
- _Модель «корабль = список деталей-заглушек, деталь ↔ уровень» — где живёт (widget/data),
  решаю технически при нарезке задач; новых зависимостей в pubspec не планируется._

## Открытые вопросы к PO

> Продуктовые вопросы (см. AGENT.md п. 2). Формат: вопрос → варианты → рекомендация.

- **Точка входа «из меню».** Полноценного меню в приложении нет (сразу `GameScreen`).
  Варианты: (а) кнопка-иконка «Корабль» на игровом экране; (б) отдельный экран-меню.
  **Рекомендация: (а)** — минимально и в границах эпика; отдельное меню — вне эпика.

> Нарезаются после Гейта 1 (AGENT.md п. 3). Ниже — предварительный контур; уточняется при старте стори.

- **Результат:** кнопка на игровом экране открывает ShipScreen; число деталей берётся из `ProgressService`; «Назад» работает.

### T3 — Тест восстановления прогресса _(рекомендован; прототип, хрупкое — persistence)_
- **Статус:** не начата
- **Модули:** application (+ widget-тест экрана)
- **Результат:** автотест: `current_level = K` → экран корабля показывает K собранных деталей. PO оставляет/вычёркивает на Гейте 1.
