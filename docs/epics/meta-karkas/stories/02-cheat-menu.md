## Ценность

PO/разработчик может **в дев-сборке выбрать уровень, мгновенно победить и задать
состояние корабля**, чтобы **проверять любую точку игры за секунды, не проходя её руками**.

## Критерии приёмки

- [ ] В дев-сборке на игровом экране есть вход в чит-меню; в релизной сборке он скрыт
  (определяется через `kDebugMode`).
- [ ] Чит «выбор уровня»: выбрал уровень K → игра перезапускается на уровне K.
- [ ] Чит «мгновенная победа»: тап → текущий уровень засчитан пройденным (прогресс +1,
  запускается текущий пост-победный поток — тот же, что после обычной победы, каким бы
  он ни был на момент стори). Реализуется на мета-уровне (`ProgressService` + навигация),
  движок не трогаем.
- [ ] Чит «установка состояния корабля»: задал «собрано N деталей» (N = 0..3) → экран
  корабля и сохранённый прогресс отражают N (через `ProgressService.setCurrentLevel`).
- [ ] `flutter analyze` — ноль; существующие тесты зелёные; читы не падают.

## Не входит

- Доступность чит-меню в релизной сборке (наоборот — скрыть).
- Правка мишеней/масок/правил укладки — ядро заморожено (VISION).
- Красивый UI — минимально функциональный список кнопок.

## Затронутые модули

- `lib/presentation/screens/` — экран/оверлей чит-меню (новый) + вход из игрового экрана.
- `lib/application/` — `ProgressService` (`setCurrentLevel`/`reset`/`advanceOnWin` уже есть).
- _Движок (`game_engine/*`) НЕ затрагивается: «мгновенная победа» имитируется на мета-уровне
  (засчитать прогресс + запустить пост-победный поток), без изменения ядра._
