## Ценность

Пользователь может **пройти весь дев-контент корабля на новом ядре укладки
(каждый уровень-деталь собирается, полный прогон до собранного корабля)**, чтобы
**эпик закрывался на зелёном, воспроизводимом проекте без остатков старого ядра**.

## Критерии приёмки

- [ ] Каждая дев-деталь (`data/ship_parts`) собирается на новом ядре: её маска
  силуэта нарезается генератором и укладывается до заполнения без дыр (маски и
  материалы переиспользованы как есть — без переделки контента).
- [ ] Сквозной смоук-сценарий переписан под укладку: полный прогон всех уровней
  контента до собранного корабля и финал-сброса проходит автотестом (аналог
  `win_flow_test` эпика «Контент», адаптированный под новое условие победы).
- [ ] Мёртвый код удалён: `lib/game_engine/rules/rotation.dart` (пустой TODO),
  `lib/application/game_loop.dart` (`GameLoop`-стуб), любые оставшиеся после
  Стори 02 хвосты взрыва/падения. `grep` по проекту не находит зомби-вызовов.
