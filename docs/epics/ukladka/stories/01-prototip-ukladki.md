## Ценность

Пользователь (PO) может **собрать деталь корабля, перетаскивая кусочки-полиомино
из подачи в силуэт детали на прототип-экране (доступен из чит-меню), с тумблером
подачи «полный набор / лоток-3»**, чтобы **пальцами на устройстве вынести вердикт:
приятен ли акт точной укладки настолько, чтобы доводить новое ядро** (главная
гипотеза VISION).

- **Рекомендованный агент:** Исполнитель (**тяжёлая**) · Claude Opus
  (`ispolnitel-heavy`). **Перед запуском** — холодная вычитка ТЗ Критиком (режим
  «ТЗ», `system/CRITIC.md` § 3): домен хрупкий (алгоритм разбиения + порог
  распределения).
- **Цель:** детерминированный генератор, режущий силуэт `TargetMask` на связные
  полиомино-кусочки по 3–5 клеток, покрывающие S полностью и без пересечений
  (решение существует по построению — генератор его строит), с тюнингом
  распределения размеров, чтобы нарезка не вырождалась в россыпь мелочи.
- **Модули (≤ 3):** `lib/game_engine/packing/` (паспорт:
  `lib/game_engine/packing/README.md`) — добавляется файл нарезки; читает
  `lib/game_engine/models/` (`TargetMask`). Использует `PackPiece` из T1.
- **Что сделать:** `lib/game_engine/packing/pack_slicer.dart`, чистый Dart (БЕЗ
  `import 'package:flutter/...'`):

  **Возвращаемый тип** (в этом же файле) — нарезка должна выражать И кусочки для
  лотка, И эталонную раскладку, доказывающую, что решение существует (её же
  использует T3 как «известно решаемое» начальное состояние; тесты проверяют по
  ней покрытие):
  ```dart
  /// Результат нарезки силуэта: кусочки (для лотка) + эталонная раскладка.
  class PackSlice {
    /// Кусочки с уникальными id (0..N-1), cells НОРМАЛИЗОВАНЫ (min x=0, min y=0).
    final List<PackPiece> pieces;
    /// pieceId → origin в координатах силуэта: положив каждый кусок в его origin,
    /// получаем полное покрытие силуэта без дыр/пересечений (решение существует).
    final Map<int, ({int x, int y})> solution;
    const PackSlice({required this.pieces, required this.solution});
  }
  ```
  - **API:** `PackSlice slicePolyomino(TargetMask silhouette, {int? seed});`
  - **Детерминизм — один источник случайности.** Всё случайное (порядок перебора
    кандидатов) берётся из ОДНОГО `math.Random(seed)` (`dart:math`), протянутого
    через весь алгоритм. При равном `seed` — побитово идентичный `PackSlice`.
    `seed == null` → `Random()` (недетерминирован). Для `PackPiece.id` — счётчик
    0..N-1 в порядке нахождения кусков (детерминирован при фиксированном seed).
  - **Алгоритм — полный бэктрекинг (DFS), гарантированно находит разбиение, если
    оно существует** (не жадное выращивание — оно застревает; см. вычитку
    Критиком). Работаем над множеством клеток `S = Set(silhouette.cells)`:
    1. Если все клетки покрыты — успех, вернуть накопленные куски.
    2. Иначе взять **якорь** = непокрытая клетка с минимальным линейным индексом
       `y*width + x` (детерминированный выбор, НЕ случайный) — гарантирует, что
       якорь всегда покрывается формируемым куском (не остаётся сирота).
    3. Перечислить все **связные (4-соседство) подмножества непокрытых клеток,
       содержащие якорь, размера 3, 4 и 5**. Порядок перебора размеров —
       **[4, 5, 3]** (сначала 4, потом 5, потом 3 — антивырождение: размер 3 —
       крайняя мера). Внутри одного размера — множество кандидатов перемешать
       единым `Random(seed)` (даёт вариативность нарезок при разных seed,
       детерминированную при равных).
    4. Для каждого кандидата по порядку: пометить его клетки покрытыми, записать
       кусок (origin = (minX,minY) его абсолютных клеток; cells = абсолютные −
       origin, т.е. нормализованные), рекурсивно решить остаток. Успех вниз →
       вернуть. Неудача → откатить (снять пометки, убрать кусок) и пробовать
       следующего кандидата.
    5. Все кандидаты якоря исчерпаны без успеха → вернуть неудачу выше (бэктрек).
    Полнота: перебор всех кусков-кандидатов якоря + бэктрекинг находит разбиение,
    если оно есть. Завершимость: дерево поиска конечно (клеток конечно). На
    реальных силуэтах-деталях (chunky, ширина ≥ 2) разбиение существует — тесты
    ниже это подтверждают на каждой контентной маске.
  - **Нормализация** — обязанность slicer'а: для каждого куска
    `origin = (min x, min y)` его абсолютных клеток; в `PackPiece.cells` кладём
    `(x-origin.x, y-origin.y)`; `solution[id] = origin`. Тогда положить
    `pieces[id]` в `solution[id]` = исходные абсолютные клетки.
  - **Грань (предусловия).** В начале: `assert(silhouette.cells.length >= 3)` и
    `assert` связности силуэта (все игровые маски валидны). Если разбиение не
    найдено (не должно случаться на контенте) — бросить `StateError` с понятным
    текстом (это НЕ штатный no-op: генератор обязан резать валидный силуэт).
    Поведение на невалидном силуэте задокументировать в `///` и README.
  - **Автотесты** `test/game_engine/packing/pack_slicer_test.dart`. Обязательный
    набор масок (все 4):
    - `defaultTargetMask` (крест 6×6, 20 клеток, `models/target_mask.dart`);
    - `ShipParts.parts[1].mask` (верхний корпус 4×3 `0xFFF`, 12 клеток);
    - `ShipParts.parts[0].mask` (нос 4×2 `0x6F`);
    - `ShipParts.parts[5].mask` (двигатель 4×2 `0xF6`).
    Для каждой маски, для **seed ∈ 0..9**:
    - **покрытие:** `⋃ (piece.cells + solution[id])` по всем кускам ==
      `Set(silhouette.cells)` (полное, без дыр);
    - **непересечение:** `Σ piece.size == silhouette.cells.length`;
    - **размеры:** каждый `piece.size ∈ {3,4,5}`;
    - **связность:** клетки каждого куска связны по 4-соседству;
    - **нормализация:** у каждого куска `min x == 0 && min y == 0`;
    - **id:** уникальны, 0..N-1.
    - **детерминизм:** `slicePolyomino(m, seed: 3)` дважды → идентичный `PackSlice`
      (pieces и solution равны).
    - **антивырождение (только крест 6×6):** для каждого seed ∈ 0..9 доля кусков
      размера 3 — **≤ 0.5** (порядок размеров [4,5,3] это легко обеспечивает;
      если алгоритм не проходит — это сигнал вернуть ТЗ Постановщику, не
      подкручивать порог вверх).
